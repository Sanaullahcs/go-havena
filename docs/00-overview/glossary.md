# Glossary

| Term | Definition |
|------|------------|
| **Community** | A single managed neighborhood (e.g. *Oak Valley, Austin TX*). The top‑level tenant boundary; almost all data is scoped to a community. |
| **Resident / Member** | A verified user who belongs to a community. Default role. |
| **Moderator** | Member with elevated rights to moderate feed content and post reminders. |
| **Admin** | Operator of a community: approves members, manages content, marketplace, analytics. |
| **Guest browsing** | Limited read‑only access to public community info **before** signup, to reduce friction. |
| **Invite code** | A code (created by an admin) that lets a user join a community directly. |
| **Notice** | An item on the Digital Notice Board: announcement, event, update, alert, reminder, or neighbor post. |
| **W‑E‑L‑L‑S** | The five wellness pillars used to organize Resource Hub content. |
| **Amenity / Facility** | A reservable community resource (pool, BBQ, tennis court, meeting room, etc.). |
| **Reservation / Booking** | A resident's scheduled use of an amenity. |
| **Coupon / Deal** | A marketplace offer published by a local business. |
| **Redemption** | The act of a resident claiming a coupon (produces a QR/confirmation). |
| **Points** | Gamification currency earned through participation. |
| **Badge** | An achievement unlocked through specific actions. |
| **Streak** | Consecutive days of engagement. |
| **Leaderboard** | Ranked list of members by points within a community. |
| **HSA** | Health Savings Account — some wellness content is HSA‑reimbursable, adding monetary value. |
| **Sanctum** | Laravel's token auth package used to issue API tokens to clients. |
| **OTP** | One‑Time Password, sent via SMS for phone verification. |
