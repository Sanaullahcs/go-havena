# The 7‑Value Framework

Every feature maps back to one or more of these seven values. When prioritizing or designing, confirm the feature serves at least one primary value.

| Value | Promise | How Havena delivers |
|-------|---------|----------------------------|
| 🏠 **Local** | "Your neighborhood's digital notice board" | Digital Notice Board: posts, events, updates, neighborhood info in one place |
| 🔒 **Safety** | "Know who's in your neighborhood" | Secure Resident Verification + AI moderation keeps content safe |
| 💰 **Monetary** | "Save money as a community" | Neighborhood Marketplace: exclusive coupons, local deals, vetted providers |
| ⚡ **Friction** | "Reduce app clutter and admin friction" | Property Management consolidates rules, documents, reservations, payments |
| 📚 **Information** | "Wellness resources delivered locally" | Resource Hub: W‑E‑L‑L‑S wellness courses; HSA‑reimbursable content |
| 🤖 **Convenience** | "Faster help and less effort" | Self‑service reservations, one‑tap payments, everything in one app |
| 💬 **Interactive** | "Your voice matters" | Moderated Community Feed with AI‑assisted moderation |
